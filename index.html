Quick Reference

Editing

Click any cell to edit it directly. Use Tab or arrow keys to navigate between cells. Press Enter to confirm, Esc to cancel.

Role (PIC / SIC / RP)

PICPilot in Command - you were the captain
SICSecond in Command - you were the first officer
RPRelief Pilot - augmented crew, not PIC/SIC
RP? badgeAuto-detected - your name wasn't listed as PIC/SIC

Model Output

Generic shows aircraft family (A320, B787). Specific shows exact variant from the catalog (A321, 787-9). Use Specific for accurate logbook records.

Customizing Columns

Use + Columns in the toolbar to show/hide columns. Scroll down to Optional Fields to add more columns like approaches, landings, training flags. Click column headers to rename them.

Keyboard Shortcuts

Ctrl+Z Undo   Ctrl+N Add row   Del Clear cell   Space Toggle checkbox
